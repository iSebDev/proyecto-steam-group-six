Sistema de Control RGB con micro:bit
Sistema inalámbrico bidireccional compuesto por una micro:bit controladora y una micro:bit receptora. La controladora permite modificar los valores RGB, guardar la configuración y consultar el estado de la receptora mediante radio.
Arquitectura
```text
                  RADIO GRUPO 25
                       │
          ┌────────────┴────────────┐
          │                         │
          ▼                         ▼
     CONTROLADORA               RECEPTORA
       ID: CTRL01                ID: RGB01
          │                         │
          │──── SET RGB ──────────>│
          │<─── ACK ───────────────│
          │──── GET STATE ────────>│
          │<─── STATE ──────────────│
          │──── SAVE ─────────────>│
          │<─── SAVED ─────────────│
```
Características
Comunicación mediante radio.
Protocolo propio para los mensajes.
Identificación mediante ID de dispositivo.
Clave compartida.
Control remoto de rojo, verde y azul.
Valores RGB de `0` a `1023`.
Guardado de la configuración en `color.txt`.
Consulta del estado actual mediante `GETSTATE`.
Comprobación de dispositivos autorizados.
Control local del RGB mediante botones y logo.
Respuestas de confirmación (`ACK`, `SAVED`, `PONG`, `STATE` y `ERROR`).
> **Nota de seguridad:** la clave transmitida permite evitar interacciones accidentales con otros dispositivos, pero no constituye cifrado criptográfico. Para un sistema realmente seguro sería necesario añadir autenticación y/o cifrado.
Protocolo de comunicación
El formato general de los mensajes es:
```text
RGB1|CLAVE|ORIGEN|DESTINO|SECUENCIA|COMANDO
```
Ejemplo:
```text
RGB1|MICRO123|CTRL01|RGB01|0001|CHANGESETT:COLOR:RED:500
```
La receptora verifica:
Protocolo correcto.
Clave correcta.
Destino correcto.
Emisor autorizado.
Secuencia no duplicada.
Ejecuta el comando.
Comandos
Cambiar color
```text
CHANGESETT:COLOR:RED:500
CHANGESETT:COLOR:GREEN:700
CHANGESETT:COLOR:BLUE:250
```
Guardar
```text
SAVE
```
Consultar estado
```text
GETSTATE
```
Comprobar conexión
```text
PING
```
Respuestas
La receptora puede responder con:
```text
ACK:...
STATE:...
SAVED
PONG
ERROR:...
```
Ejemplo:
```text
RGB1|MICRO123|RGB01|CTRL01|0001|ACK:CHANGESETT:COLOR:GREEN:100
```
Micro:bit receptora
La receptora utiliza:
`P0` → Rojo
`P1` → Verde
`P2` → Azul
`color.txt` → almacenamiento de los valores RGB.
ID → `RGB01`
Grupo de radio → `25`
Clave → `MICRO123`
Controladora autorizada → `CTRL01`
Funcionamiento local
A + B → entra o sale del modo de configuración.
A → cambia el color seleccionado.
B → cambia al siguiente color.
Logo → aumenta el valor seleccionado.
La configuración se guarda en `color.txt`.
En funcionamiento normal, el LED continúa parpadeando.
Rango RGB
Los valores utilizan el rango:
```text
0 ─────────────── 1023
```
Por ejemplo:
```text
CHANGESETT:COLOR:RED:255
```
establece:
```text
colors[0] = 255
```
Si se recibe un valor superior a `1023`, se limita automáticamente a `1023`.
Micro:bit controladora
La controladora utiliza:
ID → `CTRL01`
Receptora → `RGB01`
Grupo de radio → `25`
Clave → `MICRO123`
El menú principal es:
```text
> ROJO
  VERDE
  AZUL
```
También dispone de:
```text
> GUARDAR
> ESTADO
> CONECTAR
```
Edición de color
Al entrar en un color se muestra:
```text
COLOR: GREEN
100 / 1023
A = +20
B = enviar
```
Cada pulsación de A aumenta el valor en `20`. Al superar `1023`, vuelve a `0`.
Al pulsar B, se envía el nuevo valor a la receptora.
Ejemplo de funcionamiento
Si se selecciona verde y se establece el valor `100`, la controladora envía:
```text
RGB1|MICRO123|CTRL01|RGB01|0001|CHANGESETT:COLOR:GREEN:100
```
La receptora valida el mensaje y ejecuta:
```text
colors[1] = 100
update_leds()
```
Después responde:
```text
RGB1|MICRO123|RGB01|CTRL01|0001|ACK:CHANGESETT:COLOR:GREEN:100
```
Guardado remoto
Desde el menú GUARDAR, la controladora envía:
```text
RGB1|MICRO123|CTRL01|RGB01|0005|SAVE
```
La receptora ejecuta:
```text
save_colors()
```
Y `color.txt` puede quedar:
```text
500,100,800
```
Después responde:
```text
SAVED
```
La controladora muestra:
```text
GUARDADO OK
```
Consulta del estado
La controladora puede solicitar el estado actual:
```text
GETSTATE
```
La receptora responde, por ejemplo:
```text
STATE:500:100:800
```
La OLED muestra:
```text
RGB01 ESTADO
R:500
G:100
B:800
```
Esto permite comprobar la configuración real de la receptora en lugar de depender solamente de los valores almacenados localmente en la controladora.
Identificación de dispositivos
Cada dispositivo tiene un ID.
Ejemplo:
```text
CTRL01 → RGB01
```
Si se añade otra receptora:
```text
CTRL01 → RGB02
```
La controladora puede cambiar el destino modificando:
```text
RECEPTOR_ID = "RGB01"
```
por:
```text
RECEPTOR_ID = "RGB02"
```
Una futura versión puede permitir seleccionar varios dispositivos desde la OLED:
```text
> DISPOSITIVOS

  RGB01 ✓
  RGB02 ✓
  RGB03 ?
```

Compatibilidad
El código utiliza APIs de radio y OLED de MakeCode Python. Dependiendo de las extensiones utilizadas, algunas funciones pueden variar.
Por ejemplo, si `pause()` no está disponible, puede ser necesario utilizar:
```python
basic.pause(500)
```
También hay que tener en cuenta que las funciones de OLED dependen de la extensión instalada.

Resumen
El proyecto implementa un sistema de comunicación inalámbrica entre micro:bits mediante un protocolo con:
```text
PROTOCOLO
CLAVE
ID_EMISOR
ID_RECEPTOR
SECUENCIA
COMANDO
```
La controladora puede modificar el RGB, guardar valores, comprobar la conexión y consultar el estado de la receptora. La receptora valida los mensajes antes de ejecutarlos y devuelve respuestas para mantener una comunicación bidireccional.
