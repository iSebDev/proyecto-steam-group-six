        │                             │

Y todos los mensajes tendrán:

número de mensaje

def process_radio():

    global ultima_secuencia

    mensaje = radio.receive()

    if mensaje is None:
        return

    partes = mensaje.split("|")

    # Deben existir 6 campos
    if len(partes) != 6:
        return

    protocolo = partes[0]
    clave = partes[1]
    origen = partes[2]
    destino = partes[3]
    secuencia = partes[4]
    comando = partes[5]

    # -----------------------------------------
    # COMPROBAR PROTOCOLO
    # -----------------------------------------

    if protocolo != PROTOCOLO:
        return

    # -----------------------------------------
    # COMPROBAR CLAVE
    # -----------------------------------------

    if clave != CLAVE:
        return

    # -----------------------------------------
    # COMPROBAR DESTINO
    # -----------------------------------------

    if destino != MI_ID and destino != "*":
        return

    # -----------------------------------------
    # COMPROBAR EMISOR
    # -----------------------------------------

    if not autorizado(origen):
        return

    # -----------------------------------------
    # EVITAR DUPLICADOS
    # -----------------------------------------

    if secuencia == ultima_secuencia:
        return

    ultima_secuencia = secuencia

    # -----------------------------------------
    # PING
    # -----------------------------------------

    if comando == "PING":

        send_message(
            origen,
            secuencia,
            "PONG"
        )

        show_radio()

        return

    # -----------------------------------------
    # GETSTATE
    # -----------------------------------------

    if comando == "GETSTATE":

        send_state(
            origen,
            secuencia
        )

        return

    # -----------------------------------------
    # SAVE
    # -----------------------------------------

    if comando == "SAVE":

        save_colors()

        send_message(
            origen,
            secuencia,
            "SAVED"
        )

        show_radio()

        return

    # -----------------------------------------
    # CAMBIAR COLOR
    # -----------------------------------------

    if comando.startswith("CHANGESETT:COLOR:"):

        datos = comando.split(":")

        if len(datos) != 4:
            send_message(
                origen,
                secuencia,
                "ERROR:FORMAT"
            )
            return

        color = datos[2]

        try:
            valor = int(datos[3])
        except:
            send_message(
                origen,
                secuencia,
                "ERROR:VALUE"
            )
            return

        # Limitar 0-1023

        if valor < 0:
            valor = 0

        if valor > 1023:
            valor = 1023

        # -------------------------------------
        # ROJO
        # -------------------------------------

        if color == "RED":

            colors[0] = valor

        # -------------------------------------
        # VERDE
        # -------------------------------------

        elif color == "GREEN":

            colors[1] = valor

        # -------------------------------------
        # AZUL
        # -------------------------------------

        elif color == "BLUE":

            colors[2] = valor

        else:

            send_message(
                origen,
                secuencia,
                "ERROR:COLOR"
            )

            return

        # Actualizar LED
        update_leds()

        # Responder
        send_message(
            origen,
            secuencia,
            "ACK:" + comando
        )

        # Mostrar temporalmente la barra
        show_value()

        return

6. Una corrección importante en ese código

Como tu OLED pertenece a una extensión concreta de MakeCode, las funciones pueden ser:

OLED.write_string_new_line()
OLED.write_num_new_line()


como en tu código original.

Pero dependiendo de la extensión que estés utilizando, pause() puede no existir con ese nombre. Si tu entorno usa basic.pause(), habrá que cambiar:

pause(500)


por:

basic.pause(500)


Y lo mismo con la API de radio. Tu código original utiliza:

radio.set_group()
radio.send_value()


por lo que estoy siguiendo la API de MakeCode Python, no MicroPython puro, en la controladora.

Una cosa que cambiaría en la siguiente versión

Yo no dejaría la clave MICRO123 directamente como única medida de seguridad. Para tu proyecto está bien como primera versión, pero podemos hacer un protocolo bastante más sólido con:

RGB1
CLAVE
ID_EMISOR
ID_RECEPTOR
SECUENCIA
COMANDO
CHECKSUM


y, sobre todo, un handshake de conexión:

CTRL01                         RGB01
   │                             │
   │──── HELLO ─────────────────>│
   │                             │
   │<─── CHALLENGE ──────────────│
   │                             │
   │──── AUTH ──────────────────>│
   │                             │
   │<─── CONNECTED ───────────────│
   │                             │
   │<═══ comunicación bidireccional ═══>│


Así ya no sería simplemente "dos micro:bits que comparten un grupo", sino un pequeño sistema de dispositivos emparejados, que creo que es exactamente lo que estás buscando.
