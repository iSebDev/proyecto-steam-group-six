# Informe de Avance 2: Septiembre 202x

## 2/9/2026
Durante esta jornada se continuó trabajando sobre las funcionalidades y componentes que habían quedado en desarrollo durante la jornada anterior. El trabajo estuvo principalmente enfocado en revisar el funcionamiento del prototipo, detectar errores y solucionar algunos de los inconvenientes que se venían arrastrando de las jornadas anteriores. Debido a que todavía se encontraban en proceso de integración varias de las funcionalidades del sistema, no se produjeron grandes avances en cuanto a nuevas características, pero sí se logró mejorar el estado general del proyecto.

### Tareas completadas
*  Continuación del desarrollo del sistema de alarma visual.
*  Revisión de las funcionalidades implementadas durante las jornadas anteriores.
*  Identificación de problemas que todavía afectaban al funcionamiento del prototipo.
*  Corrección de algunos errores relacionados con el código y la integración de los componentes.
*  Realización de pruebas para comprobar las correcciones realizadas.
*  Continuación del trabajo sobre el sistema de comunicación entre dispositivos.


### Problemas encontrados y soluciones/alternativas propuestas
Durante la jornada se continuó trabajando sobre algunos problemas que habían surgido durante las etapas anteriores de desarrollo. Al tratarse de un proyecto que integra diferentes componentes y funcionalidades, algunas partes todavía presentaban comportamientos que no eran los esperados.

Se realizaron pruebas y modificaciones sobre el código y las conexiones para intentar identificar las causas de estos problemas. Si bien no se solucionaron todos los inconvenientes pendientes, se logró corregir algunos de ellos y dejar el proyecto en mejores condiciones para continuar con la integración durante las próximas jornadas.

### Próximos pasos

Para la siguiente semana se propone:
*  Continuar solucionando los problemas pendientes.
*  Finalizar la integración de las funcionalidades desarrolladas.
*  Continuar realizando pruebas con los dos dispositivos.
*  Verificar el correcto funcionamiento de la comunicación entre el dispositivo detector y el dispositivo notificador.
*  Mejorar la estabilidad del sistema.
*  Continuar con la implementación y prueba de las opciones de configuración.
