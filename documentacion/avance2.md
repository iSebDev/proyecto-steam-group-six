# Informe de Avance 2: Septiembre 202x

## 2/9/2026

Durante esta jornada se continuó trabajando sobre las funcionalidades y componentes que habían quedado en desarrollo durante la jornada anterior. El trabajo estuvo principalmente enfocado en revisar el funcionamiento del prototipo, detectar errores y solucionar algunos de los inconvenientes que se venían arrastrando de las jornadas anteriores. Debido a que todavía se encontraban en proceso de integración varias de las funcionalidades del sistema, no se produjeron grandes avances en cuanto a nuevas características, pero sí se logró mejorar el estado general del proyecto.

### Tareas completadas

*  Continuación del desarrollo del sistema de alarma visual.
*  Revisión de las funcionalidades implementadas durante las jornadas anteriores.
*  Identificación de problemas que todavía afectaban al funcionamiento del prototipo.
*  Corrección de algunos errores relacionados con el código y la integración de los componentes.
*  Realización de pruebas para comprobar las correcciones realizadas.
*  Continuación del trabajo sobre el sistema de comunicación entre dispositivos.


### Problemas encontrados y soluciones/alternativas propuestas

Durante la jornada se continuó trabajando sobre algunos problemas que habían surgido durante las etapas anteriores de desarrollo. Al tratarse de un proyecto que integra diferentes componentes y funcionalidades, algunas partes todavía presentaban comportamientos que no eran los esperados.

Se realizaron pruebas y modificaciones sobre el código y las conexiones para intentar identificar las causas de estos problemas. Si bien no se solucionaron todos los inconvenientes pendientes, se logró corregir algunos de ellos y dejar el proyecto en mejores condiciones para continuar con la integración durante las próximas jornadas.

### Próximos pasos

Para la siguiente semana se propone:
*  Continuar solucionando los problemas pendientes.
*  Finalizar la integración de las funcionalidades desarrolladas.
*  Continuar realizando pruebas con los dos dispositivos.
*  Verificar el correcto funcionamiento de la comunicación entre el dispositivo detector y el dispositivo notificador.
*  Mejorar la estabilidad del sistema.
*  Continuar con la implementación y prueba de las opciones de configuración.

## 16/9/2026

Durante esta jornada se continuó trabajando sobre los problemas y funcionalidades que habían quedado pendientes de las jornadas anteriores. El principal enfoque estuvo puesto en intentar solucionar los inconvenientes que todavía afectaban al funcionamiento del prototipo. Además, surgieron nuevos problemas relacionados con la comunicación por radio entre las distintas micro:bit, lo que dificultó el avance en la integración de los dos dispositivos y requirió realizar nuevas pruebas para identificar posibles causas.

A pesar de las dificultades técnicas, durante la jornada se logró avanzar en otros aspectos del proyecto. Se realizó un tablero de visión de producto, donde se definieron y organizaron elementos como la visión del proyecto, el grupo objetivo, sus necesidades, el producto propuesto y los objetivos de negocio. También se continuó planificando las tareas y funcionalidades que deberán abordarse durante las próximas jornadas.

### Tareas completadas

*  Continuación del trabajo sobre los problemas pendientes de jornadas anteriores.
*  Realización de pruebas relacionadas con la comunicación por radio entre las micro:bit.
*  Identificación de nuevos inconvenientes en la comunicación entre los dispositivos.
*  Análisis de posibles causas de los problemas de comunicación.
*  Elaboración de un tablero de visión de producto para el proyecto.
*  Definición de la visión, grupo objetivo, necesidades, producto y objetivos de negocio.
*  Planificación de las próximas etapas de desarrollo.

### Problemas encontrados y soluciones/alternativas propuestas

Durante la jornada continuaron algunos de los problemas que ya se habían identificado anteriormente. A estos se sumaron nuevos inconvenientes relacionados con la comunicación por radio entre las micro:bit, dificultando el intercambio de información entre el dispositivo detector y el dispositivo notificador.

Se realizaron diferentes pruebas para intentar determinar el origen de estos problemas, aunque no fue posible resolverlos completamente durante esta jornada. Debido a esto, el avance en la integración de la comunicación entre ambos dispositivos fue limitado y se decidió continuar investigando y realizando pruebas en las próximas jornadas.

Como alternativa para aprovechar la jornada, se avanzó en aspectos relacionados con la planificación y definición del proyecto. Se elaboró un tablero de visión de producto que permitió organizar con mayor claridad el propósito del sistema, los usuarios a los que está dirigido, sus necesidades y los objetivos que se buscan alcanzar.

### Próximos pasos

Para la siguiente semana se propone:
*  Continuar investigando y solucionando los problemas de comunicación por radio.
*  Realizar nuevas pruebas de comunicación entre las micro:bit.
*  Continuar solucionando los problemas pendientes del prototipo.
*  Integrar progresivamente el dispositivo detector y el dispositivo notificador.
*  Definir las funcionalidades que deberá cumplir cada dispositivo.
*  Continuar con la planificación de las próximas etapas del proyecto.
*  Realizar pruebas generales una vez solucionados los problemas de comunicación.
